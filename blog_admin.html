Come pubblicare il blog
  1. Clicca Esporta dati (dati.json) qui sotto
  2. Salva il file dati.json nella stessa cartella di blog_pubblico.html
  3. Carica entrambi i file sul tuo hosting (Netlify, GitHub Pages, qualsiasi server web)
  4. Il blog pubblico leggerà i dati dal JSON automaticamente
  5. Ogni volta che modifichi i dati, riesegui l'esportazione e ricarica solo dati.json
